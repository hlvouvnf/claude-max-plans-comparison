## 用量限制：5 小时会话 + 每周上限

Max 不是无限量，限制分三层：

1. **5 小时会话限制**：每 5 小时重置一次，Pro 和 Max 都有，Max 的额度大得多。
2. **每周通用限制**：跨所有模型计算。它在每周固定时间重置，重置时间绑定账户，和你什么时候开始用、什么时候订阅无关，每个周期能拿满全部额度。
3. **Max 专属的额外周限**：官方文档提到 Max 计划还有一个单独的、针对 Fable 模型的每周上限。

下次重置时间可以在 Settings > Usage 里查看。账号里如果有 limit reset（限制重置次数），可以用来把 5 小时会话限制或每周限制直接恢复满额。

**撞了限制怎么办？**
等重置，或在提示时选择开启 usage credits 按量继续。账号里的 limit reset 也能手动把 5 小时限制或每周限制恢复满额。
